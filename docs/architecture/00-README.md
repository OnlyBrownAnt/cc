# 设计学习笔记：Claude Code 源码快照的架构讲解

## 这份文档是什么

这是一份**学习用的架构讲解**，目的是理解一个成熟 AI 编程 CLI 的设计思路：它怎样组织"模型调用 → 工具执行 → 权限把关 → 结果回写"这条主线，以及围绕主线的上下文管理、扩展机制和会话持久化。

它**不是**功能规格书。每章讲的是结构、流程和设计理由，不描述每个功能的完整行为、边界条件或验收标准，因此读完不能据此复刻产品。

## 来源与边界

- 源码来自 `/Users/yaozhang/Desktop/cc/src`，是一个非官方的泄露快照（见仓库 README）。它不属于本文作者，也没有授权说明。
- 文中引用的文件路径和行号用于定位，行号以快照为准。
- 文档不摘录大段原代码，只引用函数名、文件名和关键常量，用来说明设计。
- 快照中的功能开关（`feature('XXX')`）只代表"源码里存在这段逻辑"，不代表线上真的启用。

## 状态标签

每个结论标注证据强度：

- **[已验证]**：读过对应代码，函数或常量确实存在，行为从代码能直接看出。
- **[推断]**：从结构或命名推出，没有完整读过实现。
- **[待确认]**：源码里看不清，需要运行时验证或其他资料印证。
